# Taskflow — To-do List

Responsive React + Vite task manager portfolio project by Tansin Habib.

## Features
- Add tasks with category and priority
- Mark tasks complete or pending
- Filter all, pending, and completed tasks
- Search and delete tasks
- Responsive desktop and mobile layout

Tasks currently live in React state and reset after a page refresh. Persistent storage is a useful next enhancement.

## Run locally
```bash
npm install
npm run dev
```

## Deploy on Vercel
1. Push these files to `https://github.com/tansinhabib26/ToDoList` on branch `main`.
2. Sign in at https://vercel.com and choose **Add New → Project**.
3. Import the `ToDoList` GitHub repository.
4. Vercel should detect Vite automatically. Build command: `npm run build`; output directory: `dist`.
5. Click **Deploy**.

## Stack
React, Vite, JavaScript, CSS, Lucide icons.
