# Taskflow — To-do List

Responsive React + Vite task manager portfolio project by Tansin Habib.

## Live Demo

🚀 **[Try Taskflow Online](https://to-do-list-roan-delta-jm2irt8jfa.vercel.app/)**

Browse the [GitHub repository](https://github.com/tansinhabib26/ToDoList) to view the source code.


## Features
- Add tasks with category and priority
- Mark tasks complete or pending
- Filter all, pending, and completed tasks
- Search and delete tasks
- Responsive desktop and mobile layout

**Note:** Tasks currently live in React state and reset after a page refresh. Persistent storage is a useful next enhancement.

## Run Locally
```bash
npm install
npm run dev
```

## Deploy on Vercel
1. Push the code to the `main` branch of the [ToDoList GitHub repository](https://github.com/tansinhabib26/ToDoList).
2. Sign in at [Vercel](https://vercel.com).
3. Choose **Add New → Project**.
4. Import the `ToDoList` GitHub repository.
5. Confirm the build command is `npm run build` and the output directory is `dist`.
6. Click **Deploy**.

## Tech Stack
React, Vite, JavaScript, CSS, Lucide icons.
